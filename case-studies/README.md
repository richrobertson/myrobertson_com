# Case studies section

This folder contains case-study landing pages and detailed delivery narratives.

## What belongs here

- `index.html`: case-study overview page
- `<case-study>/index.html`: individual case-study pages

## Authoring rules

- Keep names and URLs stable once referenced publicly.
- Include clear outcomes and architecture context in each case study.
- Ensure canonical and robots metadata reflect publication intent.

## Search readiness

Indexable case-study routes are included in sitemap generation when they pass canonical and robots checks.
