# Writing section

This folder contains long-form writing hubs and topic pages, typically as nested `index.html` routes.

## What belongs here

- `index.html`: writing landing page
- `<topic>/index.html`: topic hubs and article pages

## Authoring rules

- Keep canonical paths aligned with folder routes.
- Use `noindex,follow` for planned pages not ready for publication.
- Maintain consistent hero and metadata structure with other writing pages.

## SEO note

Sitemap generation only includes pages with matching route/canonical pairs and indexable robots directives.
