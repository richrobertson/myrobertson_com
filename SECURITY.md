# Security Policy

## Supported scope

Security reporting is supported for the default branch and production content served from this repository.

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Preferred channels:

1. GitHub Security Advisory for this repository
2. Direct private contact through the website contact page

Do not open public issues for unpatched vulnerabilities.

## What to include

- Affected path(s) and URL(s)
- Reproduction steps
- Potential impact
- Suggested remediation, if available

## Response expectations

- Initial acknowledgment target: within 5 business days
- Remediation timeline depends on severity and deployment constraints
